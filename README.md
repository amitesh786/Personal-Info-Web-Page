# Web Page

A simple JavaScript/jQuery-based webpage that performs various text processing operations (word frequency, longest word, most common letter, extract text) directly in the browser console.

## Requirements
- Any modern web browser (Chrome, Firefox, Opera, Edge, etc.).
- Basic knowledge of using the browser console.

## How to Run
- Download or clone the repository.
- Open `WebPage.html` in your preferred web browser.
- Right click anywhere on the page and choose inspect.
- In the developer tools panel, click on the console tab.
- Fill in the Last Name, First Name, and Address fields.

## Available Operations
- After filling the inputs, click one of the following buttons:

- Each Word’s Frequency
    - Displays the frequency of every word from the input fields in the console.
- Longest Word
    - Shows the longest word entered.
- Most Common Letter
    - Displays the letter with the highest frequency.
- Extract Text
    - Prints all text from the input fields.

**Notes: If all input fields are empty and you click any button, the console will display `data is empty`.**

## Setup
To run the project locally:
- Clone the repository: `git clone`
- cd ''
Then, simply open `WebPage.html` in your browser to get started.
